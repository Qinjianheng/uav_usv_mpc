# P765 动力学 / E2 离线证据

本目录只包含历史 A1_03 再分析、固定合成闭环和软件交接回归。没有启动 Gazebo/PX4，没有新解锁、飞行、A1/A2/B/C/D，也没有修改 motorConstant、Y 公式/增益、在线控制、时效或验收阈值。

权威输出为 `identification_accepted_plan/dynamics_analysis.json` 与 `e2_frozen_final/e2_analysis.json`。早期 `identification*`、`e2*` 和失败日志均保留；以各报告的 source_inputs 区分源码身份。两个命令均有意返回 2，分别表示 E0 BLOCKED / A1 NO-GO 和 E2 FAIL，不能把非零退出当工具故障。

## 动力辨识

历史物理模型质量 2.1948611354 kg，SDF 静态电机总推力上界 64.5289173797 N，对应静态 TWR 3；这不是实测最大稳态 TWR。模型转速时间常数为上升 12.5 ms / 下降 25 ms，也不是 Body-rate→Velocity 交接延迟。

满推力后的 RESET 只发 Velocity 指令，执行 collective 首次低于 0.95 为 +240.11755 ms；因此这条记录只约束旧模式退出事件。七档 Body-rate 内首个 collective 匹配请求的观察时差约 0.814–4.592 ms；它只是 setpoint 执行反馈，不能当物理电机/推力响应上界。

七档分别只有 11 条原生加速度反算力样本，80 ms 后各 7 条，共 77 / 49 条；悬停可用 100 条。最大原生导航间隔为 24.002 ms。每档 ULog actuator_motors / actuator_outputs 只有 2–3 条。ULog 虽有 604 条 esc_status 和每电机 524 条非零 esc_rpm，但当前 PX4 GZMixingInterfaceESC 源码订阅自身 `/command/motor_speed` 并回填 velocity；该字段不是独立转子测量。报告保存源文件哈希，并明确未证明历史源码与二进制的构建绑定。

E0 **BLOCKED**，A1 **NO-GO**。动力学实验暂缓；本轮唯一推荐的下一项会话是另行批准的一次 30 s 未解锁 ROI/时序采集，优先解决有效 3D 为零与 E1。固定/约束推力台输入响应辨识仅是未来可能的方法，需要独立设计与授权；可记录同一原生时钟下输入、分配、独立转速、力与误差界，但本轮不提出第二项并行实验，也不申请新的自由飞行 A1。

## E2

压力模型是 2 kg 点质量、理想分段推力映射、dt=5 ms，角速度和力各带相同一阶时间常数。500 ms 不是纯传输延迟、速度反馈陈旧或当前 PX4 实测动态；参考和反馈同刻。原固定 20 s / 末误差 <0.15 m 判据保持。

| 同时施加的 tau ms | 20 s 末误差 m | 原判据 |
|---:|---:|---|
| 20 | 0.00000145 | PASS |
| 120 | 0.00000134 | PASS |
| 240 | 0.00000141 | PASS |
| 400 | 0.00731830 | PASS |
| 440 | 0.11344041 | PASS（有限时域，非物理稳定范围） |
| 500 | 0.65810757 | **FAIL** |

500 ms 原例中加速度限幅 0 次、jerk 限幅 2569/4000 次、角速度 slew 与推力 slew 边界均 0 次；全部输出边界满足。去掉推力滞后仍失败（0.383666 m），去掉角速度滞后且保留推力滞后则收敛（0.00000251 m），指向姿态/角速度执行链的相位滞后；jerk 限幅参与非线性振荡。该模型未触发恢复策略，不能据此断言恢复启动过晚。

完整水平小信号链为 `tau*s^4+s^3+4*s^2+8*s+4`，Routh 条件给出连续时间局部稳定的严格条件 `0<tau<0.4375 s`；此前一维三阶加速度模型漏掉了姿态与角速度链。报告同时保存 5 ms 数值积分对应的离散谱半径：440 ms 数值模型略稳定而连续模型略不稳定，500 ms 两者均不稳定。因此不能把 440 ms 有限时域 PASS 描述成连续/实物最大稳定范围。400 ms 是本轮同时处于连续局部稳定域且通过有限闭环判据的最大预声明测试点；非线性连续范围仍未证明，实际物理延迟范围未知。

只比较三种预声明方案，没有网格或增益搜索：原方案、10 s 五次参考过渡、120 ms 恒速状态预测。后两者保持所有增益和限制。参考过渡把 500 ms 的 20 s 末误差降至 0.031418 m，但连续局部极点仍不稳定；恒速预测仍失败（0.540540 m）。两者均未证明 MINCO 租约、轨迹/FOV/障碍/物理安全可行性，所以不进入在线代码，也不替代原 500 ms 压力失败。

真实 runtime 的合成输入交接回归 PASS：FOLLOW/Y_HANDOVER 的 PaperController.step 调用均为 0，PAPER_INTERCEPT 为 5，PNG 初始化 1 次；旧 MINCO 重入拒绝、恢复后指导调用为零、Body-rate 唯一输出及指令连续性均满足。此证据只证明软件分派，不证明双 DKF 实际感知覆盖或飞行成功。

E2 **FAIL**，保留 500 ms 工况；Y 公式、增益及在线源码完全未改。
