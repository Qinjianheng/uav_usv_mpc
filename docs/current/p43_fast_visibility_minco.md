# P4.3 高效可见性 MINCO

本轮基点 `97c8c8c9e52b0d9f7f10595dcd7557ea2525592d`。只修改新工作区；未提交、暂存或推送。实验根目录：`data/experiments/20261009_p43_follow_optimization/`。历史报告只作背景，本页数值来自本轮原始 JSONL。红球验证仍属于仿真感知接口验证。

## 实现与保留边界

新增独立 opt-in `controllers/p43_follow_solver.py`。原P3.2、P3.3、P4.1、原完整验收及原Q/T后备仍保留。实际FOLLOW、Y后截击、Tracker定时控制和偏航仲裁未改变。不是MPC求解器，也没有把影子曲线接入PX4控制。

解析常jerk候选先生成rear与±0.6rad视点，用3个样点的完整安装姿态/整球平面裕度排序；代理不做硬拒绝、不授予安全资格。最多5候选依次严格验收，单候选只构造一次MINCO。新版夹紧顺序和排序代价与旧策略不同，质量变化不能仅归因于向量化。

最终验收使用完整XYZ/yaw系数：Bernstein安全上界或解析导数极值、精确三次yaw rate极值、名义连续推力/倾角极值、原P1整球FOV/量程/海面和共同P/V/A边界。视场按≤50ms初始网格、接近边界最多两轮细分验收，明确不是连续时间FOV证明。

## 缓存与时间契约

8条LRU只缓存目标无关的系数导数/名义姿态极值，绑定数组形状和全部字节、分段时间、yaw、完整本地相机/动力学快照、mission与clock generation。新预测始终重新插值目标、计算完整姿态、整球FOV和距离；不缓存TTL、接纳或holding。相同系数重验可减少根搜索，不允许沿用旧预测的可见性结论。

物理年龄仍使用原始导航、姿态、图像与KF epoch；执行耗时使用单调时钟。求解、序列化、重验、消息转换与发布之后继续检查预算和125ms原始输入期限。`follow_publication_final`保留成功及失败周期；最终审计记录本身的序列化在计时终点之后，不声称该记录的自记账也包含在自己的时间内。

## Q/T/yaw 与梯度

先有完整可行候选，再对一个主要候选做有界Q，预算允许时再QT；每阶段最多1次 L-BFGS-B迭代，默认25ms refinement预算（最高50ms），失败/非改善/数值异常保留已验收基线。总时域固定；2个时间logit调整3段分配，Q与yaw都限制在初值附近。起终点P/V/A和起点yaw rate按共同执行时刻保持。

目标：归一化位置、速度、动态参考加速度误差（4/25、2/9、1/9），jerk积分、jerk/视点切换、平滑整球FOV、动力学与海面罚项。位置/时间使用现有MINCO伴随链；局部几何用一次批量复步求导，不对每个优化变量重复构造MINCO。Q与QT的独立中心差分检查通过，28°下倾和非零相机平移的已知几何测试通过。

相机以FRD→NED完整规划旋转、FLU安装平移与旋转、光学右/下/前坐标计算；实际外参包含模型原点偏移，规划用`translation_flu=(0.18,0,0.39)`。在线输入仍为视觉/KF `/tracking/target_state`，真值只在离线评价中出现。

## 本轮性能归因
