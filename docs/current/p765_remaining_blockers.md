## 三维链路：能定位到哪个环节

重新解析 362 条 TargetObservation，并用完整消息 payload 哈希逐条对应原 SpatialDkfNode.receive；362 条均能在原始回调中找到。拒绝原因为：

| 原因 | 次数 |
|---|---:|
| TARGET_VECTOR_INVALID | 140 |
| YOLO_DETECTION_TIMEOUT | 121 |
| YOLO_YOLO_SOURCE_STALE_AFTER_INFERENCE | 92 |
| YOLO_SOURCE_STALE_OR_INVALID | 3 |
| POSITION_HISTORY_EMPTY | 5 |
| POSITION_TIMESTAMP_BEFORE_HISTORY | 1 |

140 个几何失败是 140 个不同采集帧，均能精确对应 RGB、depth 和检测 mask，RGB/depth 原始采集戳相同，RLE 尺寸一致。因此它们已经经过检测关联，不能直接归因于 YOLO 未看到目标。140 个 mask 均为 292 像素、包围范围 18×18，质心约 `(322.05,76.05)`；检测框中心约 `(319.24,76.32)`。这是同一静止场景、同一画面位置，没有成功对照和有效 range，无法判断距离/位置相关风险，更不能用配置 8 m 冒充实测距离。

**140 次的具体拟合子因仍未知。** 旧数据没有 depth 像素；失败观测的 valid_depth_count、depth 统计等是默认字段，不能解释成“实际测到零深度”。无法据此恢复点云、背景混入、拟合秩/条件数/半径/残差/协方差，也没有原始数据证明坐标、深度前向 X 或数值实现存在错误。本轮保留原拟合判据，没有关闭 require_valid_sphere、放宽残差或制造有效位置。

找到并修复了一个确定的**诊断身份错误**：早期 YOLO 拒绝发生在刷新 last_time_diagnostic 之前，会复用前帧字段。今后处理每对图像时先初始化当前 raw/receipt 身份。历史 216 条早期拒绝仍标为身份未证明，不回填、不按最近收包时间强配；另外 146 条可精确对应 RGB/depth/detection。

新增诊断记录 valid_depth_count、depth_ratio、min/median/MAD、fit_mode/rank/condition、fitted_radius、radius_residual、fit_position_std 和显式拒绝原因。理想拟合没有统计不确定度模型时，诊断 std 为 null，不能当作已测得零误差。ToF 模式继续使用原噪声预算、曲率可观测性和协方差拒绝。

独立射线–球相交生成的合成数据完成 writer→无损 float32 ROI→读取→严格拟合：两个已知球接受、一个平面拒绝。测试包含 endian/padding、NaN/Inf、掩码坐标、深度非量程值、退化球面片及原始身份。**这只验证工具；真实有效三维仍为 0，真实同步 2D+3D 尚未取得。** 原实际二维输出 Y 前有效 423 次，Y 后仅 1 次；三维 Y 后为 0。

## 实时性：修复了什么，哪些没有实测

EOF wrapper 的真实子进程回归确认：wrapper 退出后，PX4 所继承输入的写端仍由 launcher 持有，空闲读取不会收到 EOF；输入字符可以送达。没有重新启动 PX4，因此**没有测得 EOF 修复后的 CPU 改善幅度**。

旧数据独立分解：586 条检测，545 次实际推理；421 个“推理后过期”标签中 40 次未执行推理，旧标签混合了阶段。新代码区分推理前、推理后和发布前过期，保留原采集戳。

| 旧真实测量 | P50 | P95 | P99 / max |
|---|---:|---:|---:|
| 实际推理耗时 | 51.041 ms | 66.580 ms | 83.428 / 121.129 ms |
| 采集→检测完成年龄 | 137.595 ms | 175.162 ms | 185.621 / 213.849 ms |
| 200 Hz 实际唤醒间隔 | 4.987 ms | 6.119 ms | 8.985 / 56.746 ms |
| 200 Hz shadow 计算 | 0.570 ms | 0.976 ms | 1.100 / 1.522 ms |

旧 157 次丢周期原样保留。collector 的 CPU 为 21.913 s / 30.552 s，即 0.717 个核心，峰值 RSS 274,673,664 B；这是双 DKF、同步记录器及 shadow 共进程的负载，不能外推为全机或 PX4 负载。旧 image tick P99 为 6.872 ms、spatial tick P99 为 0.539 ms；旧包装器计时混入序列化且 receive/tick 嵌套，不能相加或当作纯算法开销。旧原始数据不足以精确拆开 bridge、DDS、排队、记录器和每一次丢周期的贡献。

最小修复：单模型推理移至单工作线程，使 ROS 可在推理期间接收并覆盖旧待处理帧；限制 OpenCV 线程，原 ONNX/BLAS/OpenMP 单线程约束保留。记录器使用有界异步写入，溢出/写入失败使会话失败；重型压缩/序列化不在 200 Hz 回调中完成。新增 source age、pending wait、compute time、publication time、原始唤醒/回调/序列化 spans、进程 CPU/RSS 和逐核 CPU 计数。时钟 generation 在发布时加锁复核，防止 reset 后旧结果仍带 valid=true。

新增采集改变了记录负载，且同时包含 EOF、worker 和 writer 修复；即使后续总体改善，也不能把改善量单独归给某一个修复。**本轮未测到新的 YOLO 有效率、双 DKF 成功率或 200 Hz 实际达标结果。**

## A1：局部响应能说明什么

SDF 静态上限为 64.528917 N、TWR=3，电机上/下行配置时间常数为 12.5/25 ms；这些是模型设定。历史最高档短窗运动反推约 60.6053 N、TWR 2.81759，不能证明最大稳态推力。七档共 77 个瞬态力样本，原 80 ms 热身后 49 个，原生导航最大间隔 24.002 ms。

240.118 ms 只测到 Body-rate→Velocity RESET 撤力；同接口内的力响应上界未知。ULog 有 esc_rpm，但当前 PX4 GZ bridge 将 motor_speed 指令回填该字段，并非独立电机转速传感器；历史源码/二进制的对应也未完全证明。短窗条件拟合能描述局部趋势，拟合标准误差不是包含模型/导航误差的安全置信界。

| 离线方案 | 可讨论的辨识内容 | 原 A1 等价/安全结论 |
|---|---|---|
| 七档固定 0.22 s 脉冲 | 历史悬停与瞬态局部力曲线 | 历史已越速，不能复飞 |
| 渐进阶跃 | 局部增益 | 分档力上界未证，安全窗口未证 |

七档继续采用静态全力最坏上界，未凭请求值较小缩减界限。原保守 0.24 s reserve 与 4 m/s² 制动也不能冒充实测同接口保证。没有安全且可辨识完整 A1 的方案，维持 NO-GO；若未来另立局部辨识资格，必须修改其定义并保留最大力/角速度/制动的独立要求。受约束推力台仅是未来方法选项，本轮不申请该实验。

## E2：500 ms 为什么失败

原压力模型是推力和角速度均施加一阶时间常数，**不是 500 ms 通信延迟，也不是历史 240 ms 的实测推广**。原固定 20 s / 5 ms 工况准确复现：

| 时间常数 | 20 s 末位置误差 | 原阈值 <0.15 m |
|---|---:|---|
| 20 / 120 / 240 ms | 约 0.0000014 m | PASS |
| 400 ms | 0.007318 m | PASS |
| 440 ms | 0.113440 m | 有限时窗 PASS，不证明稳定 |
| 500 ms | 0.658108 m | **FAIL** |

完整水平小信号姿态/角速度链特征多项式为 `tau*s^4+s^3+4*s^2+8*s+4`，连续线性局部稳定条件严格为 `tau<0.4375 s`。440 ms 在有限数值积分内通过，但连续模型已有正实部极点；不能写成稳定范围。400 ms 是同时处于该局部域且通过固定受限闭环的最大已测离散点。非线性全域、任意轨迹和实际 PX4 物理时延范围均未证明。

消融显示：只移除推力滞后仍失败（0.383666 m），只移除角速度滞后收敛（约 0.0000025 m），主要是完整姿态/角速度链及反馈相位问题。500 ms 中 jerk 限制触发 2569/4000 次，未触发加速度、角速度 slew 或推力 slew 饱和；不是简单加大推力 slew 即可解决。参考与状态在这个离线 hold 工况无 epoch 错配；恢复启动时机不在该模型覆盖范围，仍未知。

只比较预声明的两个候选：10 s 平滑参考过渡将有限末误差降到 0.031418 m，但未消除该模型的局部失稳极点，也没有 MINCO/lease/FOV/障碍可行性证明；120 ms CV 敏感性试验仍失败（0.540540 m）。两者均未接入运行时，不改变原数据时效/预测规则或 Y 增益，500 ms FAIL 保留。

交接回归仍满足：X/Y_HANDOVER 论文 step 为 0、PNG 初始化一次、旧 MINCO 撤权一次、不复活旧权限、恢复不读取目标、首次 Y 指令连续、正常控制保持 Body-rate。Y 三维 DKF 的持续估计是软件回调回归通过，实际 Y 后有效三维为 0 的事实仍在。
