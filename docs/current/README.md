# 当前开发入口

P7 配置已实现 X 后 KF/BCTRA/MINCO FOLLOW、Y 后 IBVS/PNG 安全接近，由唯一 Tracker 输出速度控制，见 [P7 使用与验证](p7_progress.md)。原 baseline/IMM 研究入口保留；MPC 尚未在线接管。P53 R11 是历史成功对照，不替代当前实测。

日常一键入口 `./scripts/uav_lab.sh` 已接入 P7 手动捕获：1–5 只选择运动方式，X 才启动 UAV 起飞与 USV 运动，Y 捕获并在当前 0.5 m 内暂停。默认为 28°/5 m 与旧 P7；2026-10-20 单次恒速八字捕获并暂停世界，原生模型冻结复核记录缺失；0.25 m 仍未通过。构建、旧基线入口与退出规则见[启动说明](startup_profile.md)。
