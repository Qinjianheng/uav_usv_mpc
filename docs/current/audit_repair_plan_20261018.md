# 六项审查缺陷修复与单次仿真计划

用户授权：全部修复后启动一次仿真验证。采用单智能体在当前工作树顺序实施；已有启动修改保留，修改前源码归档在 `data/experiments/20261018_audit_repair_01/before/`。

约束：不调整控制增益、Q/R、捕获半径或时效门槛；不引入真值反馈，不修改冻结证据或外部 PX4。先对每个问题完成失败回归、最小修复和定向验证，再进入下一项。

- [x] 终态：`MissionManagerCore` 完成后拒绝迟到消息和 tick 转移；Tracker 同任务终态锁存，`completed` 独立兜底；新 mission 才可解除。覆盖 Q/capture/failure、乱序和 R。
- [x] 启动清理：普通启动器对无法证明归属的现存 PX4 拒绝启动且不发送信号；保留 R 对当前会话的清理。执行真实 shell 分支并使用信号桩测试。
- [x] KF 时间：状态改变前拒绝未来观测；保持正常采集戳和后续有效输入。覆盖初始化和已初始化两种状态。
- [x] KF 事务：prediction 前完整验证协方差；数值更新失败保持状态、协方差及 epoch 不变。覆盖无效协方差及后续正常观测。
- [x] 坐标重置：检测位置/姿态 reset counter，切断 pose history，锁存显式导航故障；使感知、KF、预测、规划与 Tracker 拒绝继续使用旧坐标。采用失效关闭，要求 R 完整重启，不尝试无证据的在线坐标变换。覆盖重复故障、迟到消息、已有计划及首帧 counter 播种。
- [x] 分析窗口：所有 guidance 指标统一按 start/stop 过滤；区分事件终点距离与末两秒中位距离，完整处理无输入/空窗口，不改历史证据。
- [x] 最终检查：完整 pytest、指定范围 flake8、shell 语法、构建、包前缀、diff；保存最终源码指纹和复核结果。
- [x] 单次 SITL：使用新目录执行变速 S 型 X→FOLLOW→Y→0.50 m 捕获与暂停；保留所有停止条件，失败不自动复飞。检查实际 MINCO 控制权、视觉、独立同刻距离、唯一发布者和共同冻结。
- [x] 交付：逐项修复结果、单轮结果与限制、恢复入口和 SHA256。未要求提交或推送。

回归重点：相同任务 ID 下迟到消息不能解除终态；无归属进程不被触碰；拒绝观测不能改变状态；坐标故障不能靠新图像或重新发送 X/Y 解除；捕获后输出不能污染捕获前统计。
