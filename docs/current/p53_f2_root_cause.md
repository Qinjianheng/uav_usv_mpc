accepted-start唤醒后，START_MISSED由1次降为0。激活延迟P95由46.249ms降为8.391ms，

成本估计误差，P44优先分支仍可能超过当次真实预算。最后ACTIVE77的cycle78无预算，

这是可复现的实时路径优先级问题。缺少Tracker局部subscription队列，不能进一步断言CPU根因。

完整统计见每轮analysis.json的timing：请求/预测/原观测/发布间隔、求解和完整验收、
